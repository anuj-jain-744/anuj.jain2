# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2024-07-24

### Added
- Initial setup of Share Module template.
- Shared modules/functions as part of release 1.0.0:
  - `callAPI`: Function to make Generic API calls.
  - `setDefaultLanguage`: Function to set the default language for the application based on machine settings.
  - `getCurrentLanguage`: Function to provide the current language of Apps.
  - `getTranslationForKey`: Function to get translations for a given key.
  - `setUserLanguage`: Function to set the user's preferred language.
